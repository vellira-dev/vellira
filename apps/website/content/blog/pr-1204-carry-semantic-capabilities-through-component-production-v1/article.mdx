## Current limitations

The material limitation is about authority and observation. The relationships described here come from changed TypeScript declarations, parser structure, direct assignments, output projection, and static test titles. That scope can establish a reviewable source contract, but it does not prove that every runtime path executes, that every possible input is covered, or that an external consumer behaves correctly.

There is a deliberate trade-off in relying on explicit handoffs. The extra declarations and assignments require coordinated maintenance when fields move, yet they make drift visible at review time. Hiding the same relationships behind inference would reduce local repetition while making ownership of validation and projection harder to find.

Keep that boundary intact when extending the contract. A new field needs its own source-backed path and focused cases. Similarity to an existing identifier is not authority to claim the same validation, propagation, output behavior, or operational guarantee.
