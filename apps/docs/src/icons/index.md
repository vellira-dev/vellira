# Vellira Icons

Vellira Icons is the official icon library for the Vellira Design System.

The package provides a consistent set of icons for React and React Native applications with shared names, sizing, accessibility, and TypeScript support.

## Highlights

- Cross-platform React and React Native components
- Static and animated icons
- TypeScript-first API
- Tree-shakeable imports
- Accessible by default
- Consistent sizing and stroke weights

## Icon Collections

### Static Icons

Static icons are optimized for interfaces where motion is unnecessary.

Typical examples include:

- forms
- navigation
- dashboards
- tables
- settings
- administration panels

Continue to [Static Icons](/icons/static) for usage examples and the complete gallery.

### Animated Icons

Animated icons add subtle motion to improve feedback without distracting users.

Typical examples include:

- loading states
- hover interactions
- expandable navigation
- status transitions
- interactive controls

Continue to [Animated Icons](/icons/animated) for animation examples and supported icons.
