# Vellira Brand Guide

## Name

Vellira

## Tagline

Ship UI faster. Keep it consistent.

## Short description (50 words)

Vellira is a cross-platform design system for React and React Native. It provides accessible components, design tokens, and a consistent developer experience for building modern applications across web and mobile.

## Medium description (100 words)

Vellira is an open-source design system built for React and React Native. It combines accessible components, semantic design tokens, and a consistent API to help developers build high-quality interfaces across platforms. The project focuses on developer experience, type safety, accessibility, and maintainability.
